# ثيم Twilight السادس: مِسك

## الحالة

مِسك مسودة Twilight محلية لمتاجر العطور والعود والبخور، أُضيفت كاتجاه متخصص يكمّل فئة العناية والجمال في نَسَق. تتوفر لها محاكاة متجر محلية تفاعلية على `/themes/misk/preview`؛ هذه ليست معاينة Twilight ولا متجرًا مستضافًا على سلة. لا يوجد حساب شريك سلة أو متجر معاينة مرتبط بها؛ لذلك لم تُختبر على سلة أو تُقدّم أو تُعتمد.

## المكوّنات

- `home.misk-scent-hero`: حملة قابلة للتحرير للعنوان والوصف والصورة البديلة ونص الإجراء ورابطه.
- `home.misk-scent-notes`: ثلاث إلى أربع بطاقات قابلة للتحرير للنوتات العليا وقلب العطر والقاعدة والتركيز.
- لوحة برقوقية ووردية هادئة، صورة عطر تحريرية محلية، وترجمات عربية وإنجليزية.
- تُعامل كل تفاصيل النوتات والتركيز ومصدر المكونات كمحتوى يقدمه التاجر؛ لا يتحقق الثيم منها ولا يقدم ادعاءات عن العطر.

## الفحص والبناء المحلي

```bash
corepack pnpm check:twilight
corepack pnpm build:twilight
```

أو من مجلد الثيم استخدم `corepack pnpm install --frozen-lockfile` ثم `corepack pnpm check:theme` و`corepack pnpm production`. هذه الفحوص محلية فقط.

## بعد توفر حساب الشريك

1. اربط GitHub بحساب الشريك وأنشئ متجر معاينة.
2. صدّر الثيم إلى مجلد مستقل: `corepack pnpm export:twilight -- misk ../misk-twilight-theme`.
3. تحقق من الترخيص الرسمي لقاعدة الثيم واستبدل بيانات المؤلف والدعم والمستودع.
4. استخدم `salla theme preview` لاختبار الصفحات واللغتين والجوال والوصول والأداء والأمان على متجر المعاينة.
5. استكمل متطلبات الصور والسعر والدعم، ثم أرسل طلب مراجعة النشر.

لا تشارك بيانات الدخول في المحادثة. لا يُدّعى توافق أو اعتماد قبل الاختبار الفعلي ومراجعة سلة.
