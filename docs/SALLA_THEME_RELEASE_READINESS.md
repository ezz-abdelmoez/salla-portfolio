# بوابة جاهزية ثيمات سلة الستة

**الحالة في 25 سبتمبر 2026: جميع الثيمات مسودات محلية، وليست جاهزة للبيع أو التثبيت أو الاعتماد.** هذا الملف وبوابة الفحص يفرّقان بين نجاح البناء محليًا وبين قبول سلة الرسمي.

## ما حُسّن محليًا

- إزالة أسماء العملاء ونصوص التقييمات الافتراضية ذات الخمس نجوم من مكوّن آراء العملاء في الثيمات الستة. يبدأ المكوّن اختياريًا وفارغًا، ولا يظهر حتى يضيف التاجر محتوى حقيقيًا؛ توجد إرشادات تطلب موافقة أصحاب الآراء.
- المكوّن المخصص إدخال يدوي ولا يتحقق من هوية العميل أو الشراء؛ لا ينبغي وصفه بأنه «موثّق من سلة». أُبقي مكوّن `salla-reviews` الأصلي لعرض مراجعات المتجر الفعلية.
- تحسين مكوّن الآراء المخصصة: صورة العميل اختيارية، لا تشغيل تلقائي، لا عرض ثابت بعرض 830px، عنوان مناسب لتسلسل العناوين، وتسميات بديلة للصور.
- تقوية `check:theme` لكل ثيم للتحقق من الترجمات العربية والإنجليزية المستخدمة، ووجود الصور المحلية في مصدريها، وربط الأنماط، وخلو الإعدادات من شهادات العملاء المزروعة وقوالب Twig من مرشح `raw`.
- وُسِمت الحزم الست `UNLICENSED` مؤقتًا. يشير snapshot من Theme Raed إلى MIT في `package.json`، لكن ملف `LICENSE.md` المشار إليه لم يكن في snapshot؛ لا نفترض حق إعادة التوزيع دون التحقق من النص الرسمي وحفظه.

## الفحوص المحلية

ثبّت تبعيات كل مشروع ثيم (`corepack pnpm install --frozen-lockfile` من مجلده) قبل أوامر البناء. ثم شغّل:

```bash
# فحوص الثيمات الستة الساكنة
corepack pnpm check:twilight

# الفحوص ثم بناء الإنتاج لكل ثيم
corepack pnpm build:twilight

# يعيد الفحوص والبناء للستة ثم يفحص الموانع الخارجية؛ يتوقع الخروج برمز 1 حاليًا
corepack pnpm check:theme-release-readiness
```

اجتياز فحوص الملفات أو البناء لا يثبت تشغيل Twig على سلة، ولا التوافق أو الاعتماد أو جاهزية البيع. لا تغيّر نتيجة الفحص يدويًا لإخفاء مانع؛ حدّث `salla-themes/release-status.json` فقط بعد تنفيذ خطوة سلة وتسجيل نتيجتها. لا تحفظ كلمات مرور أو رموز دخول أو أسرار بوابة الشركاء في هذا المستودع.

## موانع النشر المشتركة الحالية

- بيانات المستودع والمؤلف والبريد والدعم في `package.json` و`twilight.json` ما تزال بدائل (`REPLACE-ME` و`example.com` و`Replace with...` وبريد تجريبي). يلزم وضع بيانات الناشر والمستودع والدعم الحقيقية لكل حزمة.
- لا يوجد ملف `LICENSE.md` يتضمن النص الذي يسمح بتوزيع المصدر المشتق. يجب التحقق من حقوق Theme Raed وأي أصول أو مكتبات خارجية، وإضافة النص/الإسناد الصحيحين قبل التوزيع، ثم تعديل `license` في `package.json` بما يطابق الترخيص المؤكد.
- حساب Salla Partner ومتجر المعاينة غير جاهزين في هذه المسودة. أنشئهما واربط المستودعات من بوابة سلة؛ لا حاجة لمشاركة بيانات الدخول هنا.
- يجب تشغيل `salla theme preview` واختبار **كل ثيم** على متجر معاينة: صفحات الرئيسية والمنتج والتصنيف والبحث والسلة، العربية والإنجليزية واتجاه RTL، الهاتف وسطح المكتب، الصور والمحتوى الفارغ، التنقل بلوحة المفاتيح، قارئ الشاشة، تقليل الحركة، المتصفحات، الأداء والأمان. أصلح النتائج وأعد البناء وسجّل النجاح لكل ثيم.
- يلزم إرسال كل ثيم عبر بوابة الشركاء وانتظار مراجعة سلة. لا يُستخدم وصف «معتمد» أو «متوافق عمليًا» أو «جاهز للبيع» قبل اجتياز هذا الباب.
- قبل العرض التجاري، جهّز صور العرض وبيانات السعر والدعم وسجل التغييرات وسياسة التحديثات، وتأكد أن كل البيانات التسويقية حقيقية وغير مضللة.

## سجل البوابات الرسمية

`salla-themes/release-status.json` هو سجل يدوي بسيط، وحالته الحالية `false` لحساب الشريك ومتجر المعاينة والاختبار والمراجعة لكل ثيم. حدّث العلامة المناسبة بعد إتمام الخطوة فعليًا. النجاح المحلي لا يغيّر هذه العلامات ولا يمنح اعتماد سلة.

## حدود نَسَق

واجهة نَسَق كتالوج Next.js مستقل ببيانات وتجارب Mock. هي ليست ثيم Twilight ولا متجرًا تابعًا لسلة، ولا توجد بها بوابة دفع فعلية أو مصادقة أو API حي. السلة والمفضلة والطلب تجريبية ومحلية؛ ولا تمثل معاينات React تشغيلًا فعليًا للثيمات على سلة.
