# ثيم Twilight الثالث: وَميض

## الحالة

وَميض مسودة Twilight محلية لمتاجر الإلكترونيات والأجهزة الذكية، اختيرت لتضيف مجالًا مختلفًا عن الأزياء والعناية في المشروع. لا يوجد حساب شريك أو متجر معاينة مرتبط بالمسودة؛ لم تُختبر على سلة أو تُقدّم أو تُعتمد.

## مكوّنات المسودة

- نقطة الانطلاق من Theme Raed عند snapshot `6e62385d5534c43b2710d02ab98e442ea9f51ffa`.
- `home.wameed-hero`: حملة قابلة للتحرير للنص والصورة البديلة وزر التسوق.
- `home.wameed-tech-pillars`: ثلاث إلى أربع نقاط قابلة للتحرير لشرح خصائص موثقة.
- ألوان كحلية وزرقاء مع لمسات فيروزية، وصورة أصلية محلية تجريبية، وترجمات عربية وإنجليزية.
- الإعدادات والصفحات الأساسية موروثة من قاعدة Theme Raed؛ يجب مراجعة تراخيصها وتحديثاتها قبل أي توزيع.

## فحص وبناء محلي

من جذر المشروع:

```bash
corepack pnpm check:twilight
corepack pnpm build:twilight
```

أو من مجلد الثيم استخدم `corepack pnpm install --frozen-lockfile` ثم `corepack pnpm check:theme` و`corepack pnpm production`. هذه فحوص ملفات وتجميع محلية فقط.

## بعد توفر حساب الشريك

1. اربط GitHub بحساب الشريك وأنشئ متجر معاينة.
2. صدّر الثيم إلى مجلد مستقل: `corepack pnpm export:twilight -- wameed ../wameed-twilight-theme`.
3. استبدل بيانات المؤلف والدعم والمستودع، وتحقق من نص الترخيص الرسمي قبل مشاركة الملفات.
4. شغّل `salla theme preview`، ثم اختبر التصفح والشراء الوظيفي عبر منصة سلة، RTL/LTR، الشاشات، الوصول، الأداء والأمان.
5. أرسل طلب مراجعة النشر فقط بعد استكمال المتطلبات الرسمية.

لا تُشارك بيانات دخول في المحادثة. لا يُدّعى أي توافق أو اعتماد إلى أن يتم الاختبار الفعلي ومراجعة سلة.
