# ثيم Twilight الرابع: وَرد

## الحالة

وَرد مسودة Twilight محلية لمتاجر الزهور والهدايا والمناسبات. انطلقت كخيار رابع يضيف مجالًا بصريًا مختلفًا إلى لِين للأزياء، مَدى للعناية، ووَميض للإلكترونيات. لا يوجد حساب شريك سلة أو متجر معاينة مرتبط؛ لذلك لم تُختبر المسودة على سلة أو تُقدّم أو تُعتمد.

## المكوّنات

- `home.ward-gifting-hero`: حملة قابلة للتحرير للعناوين والوصف والصورة البديلة ونص الإجراء ورابطه.
- `home.ward-occasion-guide`: ثلاث إلى أربع بطاقات مناسبات يحرّرها التاجر.
- هوية عاجية وتوتية ووردية هادئة، صورة محلية، ونصوص عربية وإنجليزية.
- لا تضيف المسودة تكاملًا لجدولة التوصيل أو تخصيص بطاقات الإهداء؛ لا بد من التحقق من خدمات المتجر الفعلية.

## فحص وبناء محلي

من جذر المشروع:

```bash
corepack pnpm check:twilight
corepack pnpm build:twilight
```

أو من مجلد الثيم استخدم `corepack pnpm install --frozen-lockfile` ثم `corepack pnpm check:theme` و`corepack pnpm production`. هذه فحوص ملفات وتجميع محلية فقط.

## بعد توفر حساب الشريك

1. اربط GitHub بحساب الشريك وأنشئ متجر معاينة.
2. صدّر الثيم: `corepack pnpm export:twilight -- ward ../ward-twilight-theme`.
3. تحقق من نص الترخيص الرسمي، واستبدل بيانات المستودع والمؤلف والدعم.
4. استخدم `salla theme preview` لاختبار الصفحات واللغتين والجوال والوصول والأداء والأمان على متجر تجريبي.
5. أرسل طلب مراجعة النشر بعد استيفاء متطلبات الشريك الرسمية.

لا تُشارك بيانات الدخول في المحادثة، ولا يُدّعى أي توافق أو اعتماد قبل الاختبار الفعلي ومراجعة سلة.
