علشان تشوفه **كواجهة متجر سلة فعلية**، الأفضل تستخدم معاينة سلة الرسمية؛ تشغيل ملفات الثيم وحدها يبني الأصول، لكنه ما يعرض متجرًا كاملًا من غير بيانات ومتجر تجريبي.

### المعاينة الكاملة على متجر تجريبي

1. جهّز حساب شريك سلة، متجرًا تجريبيًا، واربط GitHub من بوابة الشركاء. معاينة CLI تحتاج حساب الشريك وربط GitHub، وتفتح متجرًا تجريبيًا مع تحديث تلقائي عند تعديل الملفات. [وثائق معاينة الثيم](https://docs.salla.dev/422776m0)

2. صدّر الثيم الذي تريد تجربته إلى مجلد مستقل جديد. مثال لثيم **Leen** من جذر المشروع:

   ```bash
   cd /path/to/salla-portfolio
   corepack pnpm export:twilight -- leen ../leen-twilight-theme
   ```

   غيّر `leen` إلى `mada` أو `wameed` أو `ward` أو `qahwa` أو `misk` لتصدير ثيم آخر. لازم يكون مجلد الوجهة جديدًا وفارغًا؛ ملف التصدير يضع `twilight.json` في جذر الثيم المستقل.

3. اربط المجلد المستقل بمستودع GitHub وثيمك في بوابة الشركاء. بعدها ثبّت Salla CLI مرة واحدة، وسجّل الدخول، وشغّل المعاينة من مجلد الثيم:

   ```bash
   npm install -g @salla.sa/cli
   cd ../leen-twilight-theme
   corepack pnpm install --frozen-lockfile
   salla login
   salla theme preview
   ```

   سيعرض CLI المتاجر التجريبية لتختار منها. ويمكنك تحديد متجر مباشرةً باستخدام `--store=<اسم-المتجر-أو-معرّفه>`. لإيقاف المعاينة اضغط `Ctrl+C`. طريقة تثبيت CLI الرسمية موضحة [هنا](https://docs.salla.dev/422761m0).

قبل المعاينة، أضف منتجات ومحتوى للمتجر التجريبي، وأنشئ صفحات مثل «من نحن» وFAQ من لوحة سلة واربطها بقائمة المتجر. صفحة الحملة تحتاج أيضًا إلى حملة/صفحة هبوط وبيانات منتجات في المتجر التجريبي حتى يظهر محتواها.

**حاليًا، قبل تجهيز حساب الشريك والمتجر التجريبي، تقدر تبني الثيم فقط:**

```bash
cd salla-themes/leen
corepack pnpm production
```

هذا يجمّع ملفات CSS وJS ولا يعرض المتجر كاملًا. كذلك معاينة نَسَق المحلية واجهة Mock منفصلة، وليست تشغيلًا لملفات Twig الخاصة بالثيم. لا ترسل أي كلمة مرور أو رمز GitHub هنا؛ أدخل بيانات الدخول بنفسك في أدوات سلة وGitHub الرسمية.
