# ثيم Twilight الثاني: مَدى

## الحالة

مَدى هو مشروع Twilight محلي لمتاجر الجمال والعناية، بطابع حديث واحترافي. لا يوجد حتى الآن حساب شريك سلة أو متجر معاينة مرتبط بالمشروع؛ لذلك لم تُجر معاينة سلة أو اختبارات Lighthouse، ولم يُقدّم الثيم أو يُعتمد.

## ما تم إنجازه

- نقطة انطلاق من Theme Raed عند snapshot `6e62385d5534c43b2710d02ab98e442ea9f51ffa`.
- مكوّن `home.mada-routine-hero` لحملة رئيسية قابلة للتخصيص، مع صورة بديلة محلية.
- مكوّن `home.mada-routine-steps` لخطوات روتين قابلة للتحرير من لوحة الثيم.
- هوية مرئية حديثة بألوان خضراء هادئة، تخطيط متجاوب، ونصوص `ar` و`en`.
- تحديث معاينة مَدى في كتالوج نَسَق لتوضيح أنها مسودة غير مختبرة وغير قابلة للتنزيل أو التفعيل.

## أوامر البناء المحلي

```bash
cd salla-themes/mada
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

نجاح هذه الأوامر لا يغني عن الاختبار في متجر سلة تجريبي.

## بعد إنشاء حساب الشريك

1. ربط GitHub بحساب الشريك وإنشاء متجر معاينة.
2. من جذر المشروع، صدّر الثيم إلى مجلد مستقل جديد عبر `corepack pnpm export:twilight -- mada ../mada-twilight-theme`؛ يصبح `twilight.json` في جذر التصدير.
3. استبدال البريد وروابط المستودع والدعم المؤقتة.
4. تشغيل `salla theme preview` واختبار الصفحة الرئيسية والمنتج والتصنيف، RTL/LTR، الهاتف والكمبيوتر، المتصفحات والوصول والأداء.
5. مراجعة الحجم والأمان والترجمة، تجهيز صور العرض وبيانات السعر والدعم، ثم إرسال طلب مراجعة النشر.

لا تُشارك أي كلمة مرور أو رمز دخول في المحادثة؛ المصادقة والربط يتمان على جهازك/بوابة سلة.
