# ثيم Twilight الخامس: قهوة

## الحالة

قهوة مسودة Twilight محلية للمحمصات ومتاجر القهوة المختصة، أُضيفت لإكمال تنوع المجالات بعد لِين للأزياء ومَدى للعناية ووَميض للإلكترونيات ووَرد للهدايا. تتوفر لها محاكاة متجر محلية تفاعلية على `/themes/qahwa/preview` داخل نَسَق؛ هذه ليست معاينة Twilight أو متجرًا مستضافًا على سلة. لا يوجد حساب شريك سلة أو متجر معاينة مرتبط بها؛ لم تُختبر على سلة أو تُقدّم أو تُعتمد.

## المكوّنات

- `home.qahwa-origin-hero`: حملة قابلة للتحرير للعناوين والوصف والصورة البديلة ورابط التسوق.
- `home.qahwa-roast-notes`: ثلاث إلى أربع بطاقات لمعلومات المنشأ والتحميص والتحضير.
- لوحة إسبريسو وكراميل، صورة محلية، وترجمات عربية وإنجليزية.
- أضف مواصفات وبيانات مصدر موثوقة فقط؛ هذا المكوّن لا يدير المخزون أو يثبت خصائص المنتج.

## الفحص والبناء المحلي

```bash
corepack pnpm check:twilight
corepack pnpm build:twilight
```

أو من مجلد الثيم استخدم `corepack pnpm install --frozen-lockfile` ثم `corepack pnpm check:theme` و`corepack pnpm production`. هذه الفحوص محلية فقط.

## بعد توفر حساب الشريك

1. اربط GitHub بحساب الشريك وأنشئ متجر معاينة.
2. صدّر الثيم إلى مجلد مستقل: `corepack pnpm export:twilight -- qahwa ../qahwa-twilight-theme`.
3. تحقق من نص الترخيص الرسمي واستبدل بيانات المؤلف والدعم والمستودع.
4. استخدم `salla theme preview` لاختبار الصفحات واللغتين والجوال والوصول والأداء والأمان.
5. استكمل متطلبات الصور والسعر والدعم، ثم أرسل طلب مراجعة النشر.

السعر الصفري في بطاقة نَسَق تجريبي ولا يعني وجود تنزيل مجاني. لا تُشارك بيانات الدخول في المحادثة، ولا يُدّعى اعتماد أو توافق قبل الاختبار الفعلي ومراجعة سلة.
