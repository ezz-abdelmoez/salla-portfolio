# أول ثيم Twilight: لِين

## الحالة

المشروع الحالي هو تطبيق كتالوج نَسَق؛ ملفات الثيم الحقيقي موجودة في `salla-themes/leen/` كمشروع Twilight أولي. المستخدم لم ينشئ حساب شريك سلة بعد، لذلك لم يتم ربط المستودع بالبوابة، ولم يتوفر متجر معاينة، ولم تُجر اختبارات Salla Preview/Lighthouse أو مراجعة نشر.

## ما تم إنجازه في المسودة

- نقطة انطلاق من Theme Raed الرسمي عند snapshot `6e62385d5534c43b2710d02ab98e442ea9f51ffa`.
- اسم وهوية أولية لثيم لِين لفئة العبايات والأزياء.
- مكوّنان مخصصان في `twilight.json`:
  - `home.leen-editorial-hero`: عنوان، وصف، صورة بديلة، نص زر ورابط قابل للتعديل.
  - `home.leen-fit-notes`: مقدمة وثلاث ملاحظات قابلة للتحرير عن القصّة والخامة والعناية.
- أصول محلية، أنماط متجاوبة، نصوص `ar` و`en`، وفحص أولي لملفات المشروع.

## متطلبات لاحقة عند إنشاء الحساب

- ربط GitHub بحساب Salla Partner وإنشاء متجر معاينة.
- تصدير الثيم إلى مجلد مستقل جديد من جذر المشروع عبر `corepack pnpm export:twilight -- leen ../leen-twilight-theme`، ثم إنشاء/ربط مستودع GitHub وتحديث بيانات المؤلف والدعم والروابط التجريبية.
- تشغيل `salla theme preview` من جذر الثيم على متجر المعاينة.
- فحص الصفحات الأساسية، أحجام الملفات، الترجمة، الوصول، الأداء، الاستجابة، المتصفحات والأمان؛ معالجة النتائج قبل التقديم.
- إعداد لقطات المتجر وبيانات السعر والدعم وإرسال طلب المراجعة.

حتى إكمال هذه الخطوات، لا ينبغي وصف لِين بأنه متوافق مختبر أو معتمد أو متاح للتثبيت. انظر `salla-themes/leen/README.md` للتشغيل وخطوات الربط.
