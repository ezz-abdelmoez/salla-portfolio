# مِسك — ثيم Twilight للعطور والعود

**الحالة: مسودة تطوير محلية.** مِسك هي المسودة السادسة ضمن مشاريع Twilight المحلية في نَسَق، وموجّهة لمتاجر العطور والعود والبخور. لم تُربط بحساب شريك سلة أو متجر معاينة، لذلك لم تُختبر على متجر سلة أو تُقدّم أو تُعتمد، ولا ينبغي اعتبارها جاهزة للتثبيت.

تتوفر محاكاة متجر محلية على `/themes/misk/preview` داخل نَسَق، لكنها محاكاة React ببيانات وصور تجريبية، وليست تشغيلًا لقوالب Twilight أو متجرًا مستضافًا على سلة.

## اتجاه الثيم

- لوحة لونية من البرقوقي والوردي الهادئ والحجر الدافئ.
- حملة عطرية تحريرية مع صورة محلية أصلية قابلة للاستبدال من إعدادات الثيم.
- بطاقات نوتات قابلة للتحرير للنفحات العليا وقلب العطر والقاعدة والتركيز.
- نصوص عربية وإنجليزية، وصف بديل للصورة، وروابط قابلة للاختيار من قائمة Twilight.
- بيانات النوتات والتركيز وأصل المكونات أمثلة فقط؛ يجب إدخال بيانات المورد أو العلامة الموثقة.

## الفحص والبناء محليًا

يتطلب المشروع Node.js 22.18 أو أحدث وpnpm.

```bash
cd salla-themes/misk
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

ومن جذر المستودع يمكن تشغيل `corepack pnpm check:twilight` أو `corepack pnpm build:twilight`. النجاح المحلي لا يثبت التوافق أو الاعتماد من سلة.

## بعد إنشاء حساب الشريك

1. اربط GitHub من بوابة الشركاء وأنشئ متجر معاينة.
2. صدّر الثيم إلى مجلد مستقل: `corepack pnpm export:twilight -- misk ../misk-twilight-theme`.
3. تحقق من الترخيص الرسمي، واستبدل بيانات المؤلف والمستودع والدعم قبل النشر.
4. استخدم `salla theme preview` لاختبار الصفحات واللغتين والجوال والوصول والأداء والأمان على متجر المعاينة.
5. أرسل طلب مراجعة النشر بعد استكمال متطلبات الشريك.

السعر الظاهر في كتالوج نَسَق تجريبي ولا يعني تنزيلًا أو تفعيلًا. الحزمة موسومة `UNLICENSED` حتى التحقق من الحقوق والنص الرسمي للترخيص؛ راجع `UPSTREAM.md`، ولا توزّع الملفات قبله.
