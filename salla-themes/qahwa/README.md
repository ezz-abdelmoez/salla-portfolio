# قهوة — ثيم Twilight لمتاجر القهوة والمحمصات

**الحالة: مسودة تطوير محلية.** قهوة هي المسودة الخامسة ضمن مشاريع Twilight المحلية في نَسَق، وموجّهة للمحمصات ومتاجر القهوة المختصة. لم تُربط بحساب شريك سلة أو متجر معاينة، لذلك لم تُختبر على متجر سلة أو تُقدّم أو تُعتمد، ولا ينبغي اعتبارها جاهزة للتثبيت.

## اتجاه الثيم

- لوحة دافئة مستوحاة من الإسبريسو والكراميل والورق الطبيعي.
- مبني على قوالب Twilight / Theme Raed الأساسية؛ صفحات المنتج والسلة والطلب تحتاج مراجعة فعلية.
- مكوّن حملة رئيسية قابل للتحرير للنص والصورة والوصف ورابط التسوق.
- مكوّن بطاقات لمعلومات المنشأ والتحميص والتحضير؛ أضف البيانات الموثقة من مصدرها فقط.
- صورة محلية أصلية، ونصوص عربية وإنجليزية، وتخطيط متجاوب وحالات تركيز مرئية.
- لا ينفذ هذا الثيم إدارة مخزون أو بيانات منشأ أو وصفات تحضير؛ يحرر التاجر محتواه ويتحقق منه.

## البناء والفحص محليًا

يتطلب المشروع Node.js 22.18 أو أحدث وpnpm.

```bash
cd salla-themes/qahwa
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

ومن جذر المستودع يمكن تشغيل `corepack pnpm check:twilight` أو `corepack pnpm build:twilight` لفحص وبناء المسودات الخمس. النجاح المحلي لا يعني توافقًا أو اعتمادًا من سلة.

## بعد إنشاء حساب شريك سلة

1. اربط GitHub من بوابة الشركاء وأنشئ متجرًا تجريبيًا.
2. صدّر الثيم إلى مجلد مستقل جديد: `corepack pnpm export:twilight -- qahwa ../qahwa-twilight-theme`، ليكون `twilight.json` في جذر التصدير.
3. راجع تحديثات Theme Raed، وأنشئ/اربط مستودعًا مستقلًا واستبدل بيانات المؤلف والمستودع والدعم المؤقتة.
4. تحقق من نص الترخيص الرسمي، ثم استخدم `salla theme preview` لاختبار الصفحات واللغتين والجوال والوصول والأداء والأمان على متجر المعاينة.
5. جهّز صور العرض والسعر والدعم وأرسل طلب مراجعة النشر من بوابة الشركاء.

لا تشارك كلمات مرور أو رموز دخول في المحادثة؛ الربط يتم من جهازك/بوابة سلة.
