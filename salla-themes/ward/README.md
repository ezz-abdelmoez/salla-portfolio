# وَرد — ثيم Twilight للزهور والهدايا

**الحالة: مسودة تطوير محلية.** وَرد هو الثيم الرابع ضمن مسودات Twilight في نَسَق، وموجّه لمتاجر الزهور والهدايا والمناسبات. لم يُربط بحساب شريك سلة أو متجر معاينة، لذلك لم يُختبر على متجر سلة أو يُقدّم أو يُعتمد، ولا ينبغي اعتباره جاهزًا للتثبيت.

## اتجاه الثيم

- هوية تحريرية دافئة بدرجات العاجي والوردي الترابي والتوتي.
- مبني على قوالب Twilight / Theme Raed الأساسية؛ وظائف صفحات المنتج والسلة والطلب تحتاج مراجعة على متجر تجريبي.
- مكوّن حملة رئيسية قابل للتحرير للنص والصورة البديلة والرابط.
- مكوّن مناسبات يعرض ثلاثًا إلى أربع بطاقات قابلة للتخصيص من إعدادات الثيم.
- صورة حملة محلية أصلية، وترجمات عربية وإنجليزية، وحالات تركيز مرئية للوحة المفاتيح.
- لا يضيف تكاملًا لجدولة التوصيل أو تخصيص البطاقة؛ يجب تفعيل أي وظائف كهذه من إعداد المتجر والخدمات الفعلية.

### تغطية الصفحات

- أُضيف قالب حملة Twilight الرسمي `src/views/pages/landing-page.twig`، ويعرض حالة الحملة المنتهية أو المفقودة والمنتجات المحددة، مع دعم تخطيط القائمة/السلايدر والكمية والمراجعات الاختيارية بحسب أمثلة Salla.
- توثيق صفحة الهبوط يصرّح حاليًا `No schema defined`؛ لذلك يستخدم القالب فقط الحقول الظاهرة في أمثلة Usage/Components (`landing.is_expired`, `landing.products`, `landing.is_slider`, `landing.show_quantity`, و`landing.testimonials_type`). لا يعتمد `title` أو `content` أو `offer_ends_at` أو `show_store_features` الظاهرة في مقتطفات البحث وحدها.
- صفحات «من نحن» والأسئلة الشائعة والشحن والسياسات ينشئها التاجر في لوحة سلة وتُعرض عبر `page-single.twig`؛ لا تُنشأ لها أسماء ملفات صفحات مستقلة. محتوى الصفحة يُعرض كنص آمن مع الحفاظ على فواصل الفقرات.

## البناء والفحص محليًا

يتطلب المشروع Node.js 22.18 أو أحدث وpnpm.

```bash
cd salla-themes/ward
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

ومن جذر المشروع يمكن تشغيل `corepack pnpm check:twilight` أو `corepack pnpm build:twilight` لفحص وبناء المسودات الأربع. النجاح المحلي لا يعني توافقًا أو اعتمادًا من سلة.

## بعد إنشاء حساب شريك سلة

1. اربط GitHub من بوابة الشركاء وأنشئ متجرًا تجريبيًا.
2. من جذر المشروع صدّر الثيم إلى مجلد مستقل جديد: `corepack pnpm export:twilight -- ward ../ward-twilight-theme`، ليكون `twilight.json` في جذر التصدير.
3. راجع تحديثات Theme Raed وأنشئ/اربط مستودعًا مستقلًا، ثم استبدل بيانات المستودع والبريد والدعم المؤقتة.
4. تحقق من نص الترخيص الرسمي، ثم شغّل `salla theme preview` واختبر الصفحات واللغتين والجوال والوصول والأداء والأمان.
5. جهّز صور العرض والسعر والدعم، ثم أرسل طلب مراجعة النشر من بوابة الشركاء.

لا تشارك كلمات مرور أو رموز دخول في المحادثة؛ المصادقة وربط GitHub يتمان من جهازك/بوابة سلة.
