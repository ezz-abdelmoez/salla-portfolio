# سجل تغييرات مَدى

## 0.1.0 — مسودة محلية

- بدء مشروع Twilight لمتاجر الجمال والعناية بهوية حديثة واحترافية.
- إضافة مكوّن حملة رئيسية ومكوّن روتين عناية قابلين لتخصيص التاجر.
- إضافة أصول تجريبية محلية، أنماط متجاوبة، ونصوص عربية وإنجليزية.
- إضافة فحص محلي لملفات التكوين والقوالب الجديدة.
- **لم يُربط بحساب شريك سلة أو متجر معاينة، ولم يُقدّم أو يُعتمد.**
