# مَدى — ثيم Twilight لمتاجر الجمال والعناية

**الحالة: مسودة تطوير محلية.** هذا هو الثيم الثاني ضمن مشروع نَسَق، موجّه لمتاجر الجمال والعناية باتجاه بصري حديث واحترافي. لم يُربط بعد بحساب شريك سلة أو متجر معاينة، لذلك لا يُعد مختبرًا على سلة أو معتمدًا أو قابلًا للتثبيت.

## اتجاه الثيم

- تصميم نظيف بلمسات خضراء هادئة ومساحات واسعة، مخصص لعرض منتجات الجمال والعناية.
- مبني على قوالب Twilight / Theme Raed الأساسية، مع إبقاء وظائف صفحات المنتجات والسلة والطلب الموفرة من سلة.
- مكوّن حملة رئيسية قابل للتخصيص من إعدادات الثيم: نصوص، صورة بديلة، نص الإجراء ورابطه.
- مكوّن روتين عناية من 3–4 خطوات قابل للتخصيص؛ تجنب الادعاءات العلاجية غير الموثقة عند إضافة محتوى المتجر.
- ملفات ترجمة عربية وإنجليزية وصورة حملة تجريبية محلية.

### تغطية الصفحات

- أُضيف قالب حملة Twilight الرسمي `src/views/pages/landing-page.twig`، ويعرض حالة الحملة المنتهية أو المفقودة والمنتجات المحددة، مع دعم تخطيط القائمة/السلايدر والكمية والمراجعات الاختيارية بحسب أمثلة Salla.
- توثيق صفحة الهبوط يصرّح حاليًا `No schema defined`؛ لذلك يستخدم القالب فقط الحقول الظاهرة في أمثلة Usage/Components (`landing.is_expired`, `landing.products`, `landing.is_slider`, `landing.show_quantity`, و`landing.testimonials_type`). لا يعتمد `title` أو `content` أو `offer_ends_at` أو `show_store_features` الظاهرة في مقتطفات البحث وحدها.
- صفحات «من نحن» والأسئلة الشائعة والشحن والسياسات ينشئها التاجر في لوحة سلة وتُعرض عبر `page-single.twig`؛ لا تُنشأ لها أسماء ملفات صفحات مستقلة. محتوى الصفحة يُعرض كنص آمن مع الحفاظ على فواصل الفقرات.

## البناء المحلي

يتطلب Node.js 22.18 أو أحدث وpnpm.

```bash
cd salla-themes/mada
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

هذا يبني أصول Twilight محليًا فقط. لا يتضمن معاينة متجر سلة أو اختبار Lighthouse.

## عند إنشاء حساب شريك سلة لاحقًا

1. اربط حساب GitHub ببوابة الشركاء وأنشئ متجر معاينة.
2. من جذر المشروع، صدّر ملفات الثيم إلى مجلد مستقل جديد عبر `corepack pnpm export:twilight -- mada ../mada-twilight-theme`، ليكون `twilight.json` في جذر التصدير. أنشئ/اربط بعدها مستودع GitHub مستقلًا للثيم.
3. استبدل بيانات المؤلف والبريد وروابط المستودع والدعم التجريبية.
4. استخدم Salla CLI لتشغيل `salla theme preview` على متجر المعاينة، ثم اختبر الصفحات واللغتين والهاتف والكمبيوتر والوصول والأداء والأمان.
5. استكمل صور العرض وبيانات السعر والدعم، وبعدها أرسل طلب مراجعة النشر من بوابة الشركاء.

لا حاجة لمشاركة كلمات مرور أو رموز دخول في المحادثة؛ الربط يتم من جهازك/بوابة سلة بعد إنشاء الحساب.

## بيانات مؤقتة

الروابط والبريد في `twilight.json` و`package.json` قيم مؤقتة يجب استبدالها قبل ربط GitHub أو التقديم. حالة الثيم غير منشورة وغير معتمدة.
