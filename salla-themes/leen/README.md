# لِين — ثيم Twilight لمتاجر العبايات والأزياء

**الحالة: مسودة تطوير محلية.** بدأنا أول ثيم حقيقي لمنصة سلة داخل هذا المستودع، منفصلًا عن واجهة كتالوج نَسَق. لا يملك المشروع حتى الآن ربطًا بحساب شريك سلة أو متجر معاينة؛ لذلك لم يُختبر على متجر سلة، ولم يُقدّم للمراجعة أو يُعتمد. وجود ملفات Twilight لا يعني أن الثيم جاهز للبيع أو التثبيت.

## اتجاه الثيم

- تجربة تحريرية هادئة تناسب متاجر العبايات والأزياء النسائية.
- مبني على بنية Twilight / Theme Raed الرسمية، مع إبقاء قوالب التجارة الأساسية ومكوّنات سلة الوظيفية.
- مكوّن حملة رئيسية قابل للتخصيص: العنوان، النص، الصورة البديلة، وصف الصورة، نص الزر ورابطه.
- مكوّن «تفاصيل لِين» قابل للتخصيص لشرح القصّة والخامة والعناية، ببطاقات قابلة للتحرير.
- محتوى عربي وإنجليزي عبر ملفات `src/locales`، مع تصميم متجاوب للصفحات الأساسية.
- صورة حملة تجريبية محلية؛ يستطيع التاجر استبدالها من إعدادات المكوّن.

### تغطية الصفحات

- أُضيف قالب حملة Twilight الرسمي `src/views/pages/landing-page.twig`، ويعرض حالة الحملة المنتهية أو المفقودة والمنتجات المحددة، مع دعم تخطيط القائمة/السلايدر والكمية والمراجعات الاختيارية بحسب أمثلة Salla.
- توثيق صفحة الهبوط يصرّح حاليًا `No schema defined`؛ لذلك يستخدم القالب فقط الحقول الظاهرة في أمثلة Usage/Components (`landing.is_expired`, `landing.products`, `landing.is_slider`, `landing.show_quantity`, و`landing.testimonials_type`). لا يعتمد `title` أو `content` أو `offer_ends_at` أو `show_store_features` الظاهرة في مقتطفات البحث وحدها.
- صفحات «من نحن» والأسئلة الشائعة والشحن والسياسات ينشئها التاجر في لوحة سلة وتُعرض عبر `page-single.twig`؛ لا تُنشأ لها أسماء ملفات صفحات مستقلة. محتوى الصفحة يُعرض كنص آمن مع الحفاظ على فواصل الفقرات.

## بناء الملفات محليًا

يتطلب المشروع Node.js 22.18 أو أحدث وpnpm.

```bash
cd salla-themes/leen
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

ينتج Webpack ملفات الثيم في `public/`. هذا فحص بناء محلي فقط؛ لا يستبدل معاينة سلة أو اختبارات Lighthouse على متجر تجريبي.

## بعد إنشاء حساب شريك سلة

1. اربط حساب GitHub من بوابة الشركاء وأنشئ متجرًا تجريبيًا.
2. من جذر المشروع، صدّر ملفات الثيم إلى مجلد مستقل جديد عبر `corepack pnpm export:twilight -- leen ../leen-twilight-theme`. يصبح `twilight.json` في جذر التصدير؛ بعد ذلك أنشئ/اربط مستودع GitHub وحدّث روابط المستودع وبيانات الدعم والبريد في `package.json` و`twilight.json`.
3. راجع تغييرات Theme Raed وTwilight الحالية قبل المزامنة؛ هذا المشروع نقطة بداية مشتقة من snapshot وليست مزامنة تلقائية.
4. ثبّت Salla CLI وسجّل الدخول من جهازك، ثم نفّذ `salla theme preview` واختر متجر المعاينة.
5. اختبر واجهات الرئيسية والمنتج والتصنيف والسلة، العربية والإنجليزية، الهاتف والكمبيوتر، المتصفحات، الوصول والأداء. أعد البناء بعد أي تعديل.
6. بعد استكمال صور العرض وبيانات السعر والدعم، قدّم طلب النشر من بوابة الشركاء لمراجعة سلة.

> لا حاجة لمشاركة كلمة مرور أو رمز دخول هنا. عندما تنشئ الحساب، يكفي أن تخبرني أن الحساب ومتجر المعاينة أصبحا جاهزين؛ تسجيل الدخول وربط GitHub يتمان من جهازك/بوابة سلة.

## بيانات مؤقتة يجب استبدالها قبل التقديم

- `repository`: رابط المستودع المستقل للثيم.
- `author_email` / بيانات المؤلف: البريد الذي سيُعتمد للدعم.
- `support_url`: صفحة الدعم الفعلية.
- صور المعاينة، متجر العرض، السعر، وسجل التغييرات.

## الفحوص الحالية وحدودها

- `check:theme` يتحقق من إعدادات Twilight والحقول والترجمات العربية/الإنجليزية وأصول الصور المحلية؛ كما يمنع شهادات العملاء المزروعة ومرشح Twig `raw`.
- `production` يتحقق من تجميع الأصول محليًا.
- لم تُشغّل بعد `salla theme preview` ولا اختبارات متجر سلة أو Lighthouse، لأن حساب الشريك لم يُنشأ بعد.
- لا يُذكر الثيم في واجهة نَسَق على أنه معتمد أو قابل للتثبيت؛ تبقى معايناتها محلية حتى إكمال الربط والمراجعة.
