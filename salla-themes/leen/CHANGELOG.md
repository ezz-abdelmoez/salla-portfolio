# سجل تغييرات لِين

## 0.1.0 — مسودة محلية

- بدء مشروع Twilight مستقل لثيم لِين لمتاجر العبايات والأزياء النسائية.
- إضافة مكوّن حملة تحريرية رئيسية ومكوّن تفاصيل القصّة والخامة، وكلاهما قابل للتخصيص من إعدادات الثيم.
- إضافة اتجاه بصري متجاوب وصورة حملة محلية تجريبية.
- إضافة الترجمة العربية والإنجليزية وفحص محلي لملفات الثيم.
- **غير متصل بحساب شريك سلة، وغير معاين أو معتمد حتى الآن.**
