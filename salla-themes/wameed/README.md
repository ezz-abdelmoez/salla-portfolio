# وَميض — ثيم Twilight لمتاجر الإلكترونيات

**الحالة: مسودة تطوير محلية.** وَميض هو الثيم الثالث ضمن مشاريع Twilight المحلية في نَسَق، واتجاهه لمتاجر الإلكترونيات والأجهزة الذكية. لم يُربط بحساب شريك سلة أو متجر معاينة، لذلك لم يُختبر على متجر سلة أو يُقدّم أو يُعتمد، ولا ينبغي اعتباره جاهزًا للتثبيت.

## اتجاه الثيم

- نظام بصري تقني هادئ: كحلي عميق، أزرق واضح ولمسات فيروزية.
- مبني على قوالب Twilight / Theme Raed الأساسية؛ صفحات المنتج والسلة والطلب تعتمد على قوالب البداية المضمّنة.
- مكوّن حملة رئيسية قابل للتحرير للعناوين والوصف والصورة والنص والرابط.
- مكوّن مزايا تقنية قابل للتحرير من ثلاث إلى أربع نقاط، مع توجيه لإدخال مواصفات موثقة فقط.
- ملفات ترجمة عربية وإنجليزية، وصورة حملة محلية مولدة لهذا المشروع.
- أنماط متجاوبة مع الجوال وحالات تركيز مرئية للأزرار.

### تغطية الصفحات

- أُضيف قالب حملة Twilight الرسمي `src/views/pages/landing-page.twig`، ويعرض حالة الحملة المنتهية أو المفقودة والمنتجات المحددة، مع دعم تخطيط القائمة/السلايدر والكمية والمراجعات الاختيارية بحسب أمثلة Salla.
- توثيق صفحة الهبوط يصرّح حاليًا `No schema defined`؛ لذلك يستخدم القالب فقط الحقول الظاهرة في أمثلة Usage/Components (`landing.is_expired`, `landing.products`, `landing.is_slider`, `landing.show_quantity`, و`landing.testimonials_type`). لا يعتمد `title` أو `content` أو `offer_ends_at` أو `show_store_features` الظاهرة في مقتطفات البحث وحدها.
- صفحات «من نحن» والأسئلة الشائعة والشحن والسياسات ينشئها التاجر في لوحة سلة وتُعرض عبر `page-single.twig`؛ لا تُنشأ لها أسماء ملفات صفحات مستقلة. محتوى الصفحة يُعرض كنص آمن مع الحفاظ على فواصل الفقرات.

## البناء والفحص محليًا

يتطلب المشروع Node.js 22.18 أو أحدث وpnpm.

```bash
cd salla-themes/wameed
corepack pnpm install --frozen-lockfile
corepack pnpm check:theme
corepack pnpm production
```

يمكن أيضًا تشغيل `corepack pnpm check:twilight` أو `corepack pnpm build:twilight` من جذر المشروع لفحص وبناء الثيمات الثلاثة. النجاح محلي ولا يغني عن تجربة متجر سلة.

## بعد إنشاء حساب شريك سلة

1. اربط GitHub من بوابة الشركاء وأنشئ متجرًا تجريبيًا.
2. من جذر المشروع، صدّر ملفات الثيم إلى مجلد مستقل جديد: `corepack pnpm export:twilight -- wameed ../wameed-twilight-theme`. يصبح `twilight.json` في جذر التصدير.
3. راجع تحديثات Theme Raed، وأنشئ/اربط مستودعًا مستقلًا، ثم استبدل روابط المستودع والبريد والدعم المؤقتة في `package.json` و`twilight.json`.
4. بعد التحقق من نص الترخيص الذي ينطبق على المصدر، شغّل `salla theme preview` على متجر المعاينة واختبر الصفحات، اللغتين، الجوال، الوصول، الأداء والأمان.
5. جهّز صور العرض والسعر والدعم ثم أرسل طلب مراجعة النشر من بوابة الشركاء.

لا تشارك كلمات مرور أو رموز دخول في المحادثة؛ المصادقة وربط GitHub يتمان من جهازك/بوابة سلة.

## بيانات مؤقتة وحدود الترخيص

تظل روابط المستودع والبريد و`support_url` قيمًا بديلة. لا يحتوي هذا المشروع على ملف `LICENSE.md` رسمي للمصدر؛ يذكر upstream ترخيص MIT في `package.json` لكن الملف المشار إليه في README غير موجود في snapshot. لذلك لا يمنح هذا المستودع حق إعادة التوزيع؛ تحقق من نص الترخيص الرسمي واحفظه قبل أي توزيع. راجع `UPSTREAM.md` للتفاصيل.
